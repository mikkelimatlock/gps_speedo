  ```dart
  if (_hasFirstFix && _firstFixTime != null) {
    final timeSinceFirstFix = DateTime.now().difference(_firstFixTime!);
    if (timeSinceFirstFix >= GpsConfig.PRECISION_SWITCH_FIRST_FIX_DELAY) {
      _checkPrecisionSwitch(position.speed);
    }
  }
  ```

**Add precision switching methods:**
- `_checkPrecisionSwitch(double speedMps)`:
  - If currently HIGH and speed < PRECISION_DOWN_THRESHOLD_MPS: switch to medium
  - If currently MEDIUM and speed > PRECISION_UP_THRESHOLD_MPS: switch to high
  - Per user decision: "favor accuracy over battery" -- when in doubt, stay high
  - Log precision change at debug level only (user decision: invisible to user)
- `_switchPrecision(LocationAccuracy newAccuracy)`:
  - Set `_currentAccuracy = newAccuracy`
  - Cancel existing `_gpsSubscription`
  - Create new subscription via `GpsService.createPositionStream(accuracy: newAccuracy).listen(...)`
  - Log: `Logger.debug('Precision switched to $newAccuracy at ${(speedMps * 3.6).toStringAsFixed(1)} km/h', 'GpsDataManager')`

**Implement lifecycle handlers:**
- Override `didChangeAppLifecycleState(AppLifecycleState state)`:
  - On `AppLifecycleState.paused`:
    - Set `_isAppInForeground = false`
    - Check `_overlayProvider?.isOverlayActive ?? false`
    - If overlay active: log "maintaining full GPS", do nothing to GPS
    - If overlay NOT active: start grace period timer (7s BACKGROUND_GRACE_PERIOD)
    - Call `_updateWakeLock()`
  - On `AppLifecycleState.resumed`:
    - Set `_isAppInForeground = true`
    - Cancel grace period timer if running
    - If GPS was stopped (`_gpsSubscription == null` and `_isInitialized`): restart GPS via `_restartGps()`
    - Call `_updateWakeLock()`
- Grace period timer callback: `_onGracePeriodExpired()`:
  - IMPORTANT: Check overlay state again at expiry (not at start) to handle race condition where overlay activated during grace period
  - If overlay is now active: log "overlay became active during grace, keeping GPS", cancel and return
  - Otherwise: call `_stopGps()`

**Add GPS stop/restart methods:**
- `_stopGps()`:
  - Cancel `_gpsSubscription`, set to null
  - Set `_isGpsActive = false`
  - Do NOT clear `_currentData` -- keep last known data (user decision: show last known speed as stale)
  - Cancel `_staleDataTimer`
  - Call `_updateWakeLock()`
  - Log: `Logger.info('GPS stopped (backgrounded without overlay)', 'GpsDataManager')`
- `_restartGps()`:
  - Log: `Logger.info('Restarting GPS (app foregrounded)', 'GpsDataManager')`
  - Create new subscription via `GpsService.createPositionStream(accuracy: _currentAccuracy).listen(...)`
  - Set `_isGpsActive = true`
  - Call `_updateWakeLock()`
  - Do NOT update timestamp on old data -- let staleness show naturally per user decision ("show last known speed until fresh data arrives")

**Add wake lock management:**
- `_updateWakeLock()`:
  - `final overlayActive = _overlayProvider?.isOverlayActive ?? false;`
  - `final shouldKeepAwake = _isGpsActive && (overlayActive || _isAppInForeground);`
  - If shouldKeepAwake: `WakelockPlus.enable()`
  - Else: `WakelockPlus.disable()`
  - Log at debug level with state breakdown

**Update `dispose()`:**
- Add BEFORE existing cleanup: `WidgetsBinding.instance.removeObserver(this);`
- Add: `_backgroundGracePeriodTimer?.cancel();`
- Add: `WakelockPlus.disable();` as safety net
- Keep all existing cleanup (subscription, stale timer, data controller)
