**main.dart** (`lib/main.dart`):

- Wire GpsDataManager to know about OverlayProvider for lifecycle decisions.
- The challenge: GpsDataManager is created before OverlayProvider in the MultiProvider tree. We need to pass the overlay reference after both are created.
- Approach: Use `ChangeNotifierProxyProvider2`'s update callback to also set the overlay reference on GpsDataManager. OR use a simpler approach:
  - Change GpsDataManager from `ChangeNotifierProvider` to `ChangeNotifierProxyProvider<OverlayProvider, GpsDataManager>`:
    ```dart
    ChangeNotifierProxyProvider<OverlayProvider, GpsDataManager>(
      create: (_) => GpsDataManager(),
      update: (_, overlay, gpsManager) => gpsManager!..setOverlayProvider(overlay),
    ),
    ```
  - WAIT: This creates a circular dependency! OverlayProvider depends on GpsDataManager (via ProxyProvider2), and now GpsDataManager would depend on OverlayProvider. Provider doesn't allow circular proxy dependencies.

- **Better approach**: Keep GpsDataManager as a plain `ChangeNotifierProvider`. Wire the overlay reference from SpeedometerScreen's `initState()` (after post-frame callback, when both providers are available):
  ```dart
  WidgetsBinding.instance.addPostFrameCallback((_) {
    _initializeGpsManager();
    context.read<OverlayProvider>().onError = _handleOverlayError;
    // Wire overlay provider into GPS manager for lifecycle decisions
    context.read<GpsDataManager>().setOverlayProvider(context.read<OverlayProvider>());
  });
  ```
  This is already in `initState()` inside the post-frame callback, so just add the one line.

- **Actually, even better**: Wire it in main.dart without circular deps by using a regular Provider and a post-creation callback. But the simplest reliable approach is SpeedometerScreen's initState, which already has the post-frame callback pattern. Go with that.

- So main.dart changes are MINIMAL or NONE. The wiring happens in SpeedometerScreen's initState (already modified in Task 1).

- **Update SpeedometerScreen's initState (addendum to Task 1)**: Add this line in the existing `addPostFrameCallback`:
