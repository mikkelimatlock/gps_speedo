  <action>
1. Add `retry: ^3.1.2` to pubspec.yaml under dependencies (after shared_preferences). Run `flutter pub get` to install.

2. Create `lib/services/overlay_service.dart` — a service class that wraps all FlutterOverlayWindow platform calls:

   - **Constructor:** No parameters needed. Create a static `RetryOptions` with maxAttempts: 3 and delayFactor: Duration(milliseconds: 200).

   - **showOverlay({required int width, required int height})** → Future<bool>:
     - Uses retry to call FlutterOverlayWindow.showOverlay with enableDrag: true, overlayTitle: "Speedometer", overlayContent: 'Speedo overlay active', flag: OverlayFlag.defaultFlag, visibility: NotificationVisibility.visibilityPublic, positionGravity: PositionGravity.none, plus width/height params.
     - After showOverlay completes, calls FlutterOverlayWindow.isActive() to verify overlay actually opened.
     - Returns true if verified active, false if not.
     - On exception after retries exhausted, logs via Logger.error and returns false.
     - retryIf should catch Exception (broad, since platform exceptions vary).

   - **closeOverlay()** → Future<bool>:
     - Uses retry to call FlutterOverlayWindow.closeOverlay().
     - Returns true on success, false on failure after retries.
     - Logs errors via Logger.error.

   - **shareData(Map<String, dynamic> data)** → Future<void>:
     - Calls FlutterOverlayWindow.shareData(data).
     - Catches exceptions and logs via Logger.warn (NOT error — data loss is expected and handled by staleness).
     - Does NOT retry — fire-and-forget by design (user decision: forward every tick, staleness handles drops).

   - **isActive()** → Future<bool>:
     - Delegates to FlutterOverlayWindow.isActive() with try-catch.
     - Returns false on error.

   - **get overlayListener** → Stream<dynamic>:
     - Returns FlutterOverlayWindow.overlayListener (direct delegation).

   - **checkPermission()** → Future<bool>:
     - Uses Permission.systemAlertWindow.isGranted from permission_handler.
     - Returns the boolean result.

   Import: flutter_overlay_window, retry, permission_handler, logger.dart.
   Use Logger with caller tag 'OverlayService' for all log calls.

3. Add staleness constants to `lib/config/overlay_constants.dart`:
   - `static const Duration STALENESS_DIM_THRESHOLD = Duration(seconds: 3);` — time after which overlay dims speed display (user decision: 3 seconds, NOT 2)
   - `static const Duration STALENESS_DASH_THRESHOLD = Duration(seconds: 10);` — time after which overlay shows "--" dashes
   - `static const double STALENESS_DIM_OPACITY = 0.5;` — opacity value for dimmed stale state
   - `static const Duration STALENESS_CHECK_INTERVAL = Duration(seconds: 1);` — how often overlay checks for staleness

4. Add GPS grace period constant to `lib/config/timing_constants.dart`:
   - `static const Duration GPS_GRACE_PERIOD = Duration(seconds: 30);` — GPS continues 30s after overlay close when backgrounded (user decision)
