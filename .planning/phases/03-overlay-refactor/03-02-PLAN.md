**OverlayProvider refactor (lib/providers/overlay_provider.dart):**

1. **Add OverlayService dependency:**
   - Add `final OverlayService _overlayService;` field.
   - Update constructor: `OverlayProvider(this._overlayService);`
   - Import overlay_service.dart.

2. **Add error callback mechanism:**
   - Define enum at top of file (or in separate model if preferred):
     ```dart
     enum OverlayError { permission, creationFailed, communicationDegraded }
     ```
   - Add field: `void Function(OverlayError)? onError;`
   - This is set by SpeedometerScreen after provider is available (not constructor param — allows late binding since screen needs BuildContext for snackbar).

3. **Refactor showOverlay():**
   - BEFORE calling showOverlay, check permission via `_overlayService.checkPermission()`. If denied, call `onError?.call(OverlayError.permission)` and return early.
   - Replace direct FlutterOverlayWindow.showOverlay call with `_overlayService.showOverlay(width: ..., height: ...)`.
   - Check the return value (bool). If false, call `onError?.call(OverlayError.creationFailed)` and return early.
   - ONLY set `_isOverlayActive = true` AFTER showOverlay returns true (verified by OverlayService.isActive check inside).
   - Keep the initial data push (shareData via _overlayService.shareData instead of direct FlutterOverlayWindow.shareData).
   - Keep _startListeningToOverlayMessages() and _startOverlayStatusCheck() calls.

4. **Refactor closeOverlay():**
   - Replace direct FlutterOverlayWindow.closeOverlay with `_overlayService.closeOverlay()`.
   - Keep existing _handleOverlayClose() call.

5. **Refactor _pushDataToOverlay():**
   - Replace direct FlutterOverlayWindow.shareData with `_overlayService.shareData(message.toMap())`.
   - The OverlayMessage.updateDisplay factory already auto-stamps DateTime.now() (from Plan 01 Task 2).

6. **Refactor _startListeningToOverlayMessages():**
   - Replace `FlutterOverlayWindow.overlayListener` with `_overlayService.overlayListener`.

7. **Add GPS grace period to _handleOverlayClose():**
   - Add `Timer? _gracePeriodTimer;` field.
   - In _handleOverlayClose: After setting _isOverlayActive = false, start a 30-second grace period timer using `TimingConfig.GPS_GRACE_PERIOD`.
   - The grace period timer just logs when it expires: `Logger.info('GPS grace period expired', 'OverlayProvider')`.
   - Cancel grace period in dispose().
   - Note: Actual GPS subscription lifecycle management is Phase 4 scope. The timer is created here as infrastructure but does not yet control GPS subscription start/stop. This avoids scope creep.

8. **Cancel grace period when overlay reopens:**
   - In showOverlay(), cancel `_gracePeriodTimer` if running (user reopened overlay within grace period).

9. **Refactor _startOverlayStatusCheck():**
   - Replace `FlutterOverlayWindow.isActive()` with `_overlayService.isActive()`.

**main.dart update:**

10. Update MultiProvider in main.dart:
    - Add `Provider<OverlayService>(create: (_) => OverlayService()),` BEFORE the OverlayProvider.

**Overlay screen staleness (lib/screens/overlay_screen.dart):**

1. **Add staleness monitoring:**
   - Import overlay_constants.dart (for STALENESS_DIM_THRESHOLD, STALENESS_DASH_THRESHOLD, STALENESS_DIM_OPACITY, STALENESS_CHECK_INTERVAL).
   - Add field: `DateTime _lastUpdateTime = DateTime.now();`
   - Add field: `Timer? _stalenessCheckTimer;`

2. **Start staleness check timer in initState():**
   - After existing _listenToMainAppMessages() call, add _startStalenessMonitoring().
   - _startStalenessMonitoring() creates a Timer.periodic with OverlayConfig.STALENESS_CHECK_INTERVAL (1 second).
   - Timer callback checks `if (!mounted) return;`, then:
     - Calculates age: `DateTime.now().difference(_lastUpdateTime)`
     - If age > STALENESS_DASH_THRESHOLD (10s) AND _speedText is not already '--': `setState(() => _speedText = '--');`
     - The dimming (3s threshold) is handled in build() via opacity, no setState needed for it.

3. **Update _listenToMainAppMessages() to track timestamp:**
   - When processing 'updateDisplay' messages, extract timestamp from message:
     ```dart
     _lastUpdateTime = message.timestamp;
     ```
   - This uses the timestamp from OverlayMessage (added in Plan 01 Task 2).
   - On receiving fresh data, _speedText gets the actual speed value — this is the "immediate snap-back" (no animation, just setState with new value).

4. **Update build() for staleness dimming:**
   - At the start of build(), calculate:
     ```dart
     final age = DateTime.now().difference(_lastUpdateTime);
     final isStale = age >= OverlayConfig.STALENESS_DIM_THRESHOLD;
     final staleOpacity = isStale ? OverlayConfig.STALENESS_DIM_OPACITY : 1.0;
     ```
   - Apply staleOpacity to the speed text color: change `color: currentTheme.speedText` to `color: currentTheme.speedText.withValues(alpha: staleOpacity)` for the speed Text widget.
   - Apply staleOpacity to the unit text color similarly.
   - Apply staleOpacity to the heading icon and heading text colors.
   - Do NOT use AnimatedOpacity — user decision is "immediate snap-back, no fade-in animation". Direct color alpha is correct.

5. **Cancel staleness timer in dispose():**
   - Add `_stalenessCheckTimer?.cancel();` before super.dispose().

**SpeedometerScreen error surfacing (lib/screens/speedometer_screen.dart):**

6. **Register error callback on OverlayProvider:**
   - Import permission_handler (for openAppSettings).
   - In initState() addPostFrameCallback, after _initializeGpsManager(), set up the error callback:
     ```dart
     context.read<OverlayProvider>().onError = _handleOverlayError;
     ```

7. **Implement _handleOverlayError(OverlayError error):**
   - Check `if (!mounted) return;`
   - Determine message and action based on error type:
     - `OverlayError.permission`: message = 'Overlay permission required', add SnackBarAction with label 'Settings' that calls `openAppSettings()` (from permission_handler).
     - `OverlayError.creationFailed`: message = 'Failed to create overlay window', no action button.
     - `OverlayError.communicationDegraded`: message = 'Overlay communication degraded', no action button.
   - Show snackbar:
     ```dart
     ScaffoldMessenger.of(context).showSnackBar(
       SnackBar(
         content: Text(message),
         action: action,
         duration: const Duration(seconds: 4),
       ),
     );
     ```

8. **Clean up error callback in dispose():**
   - Before super.dispose(), null out the callback:
     ```dart
     context.read<OverlayProvider>().onError = null;
     ```
   - Use a try-catch since the provider might already be disposed.
