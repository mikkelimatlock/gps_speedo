**Provider wiring order (dependencies first):**
```dart
MultiProvider(
  providers: [
    // 1. Raw dependencies (no ChangeNotifier)
    Provider<SharedPreferences>.value(value: prefs),

    // 2. Independent ChangeNotifiers
    ChangeNotifierProvider(
      create: (context) => SettingsProvider(context.read<SharedPreferences>()),
    ),
    ChangeNotifierProvider(
      create: (_) => GpsDataManager(),
    ),

    // 3. Dependent ChangeNotifier (depends on GPS + Settings)
    ChangeNotifierProxyProvider2<GpsDataManager, SettingsProvider, OverlayProvider>(
      create: (_) => OverlayProvider(),
      update: (_, gpsManager, settings, overlay) => overlay!
        ..updateDependencies(
          gpsManager: gpsManager,
          currentUnit: settings.currentUnit,
          currentThemeIndex: settings.currentThemeIndex,
        ),
    ),
  ],
  child: const SpeedoApp(),
)
```

**Changes to SpeedoApp:**
- Remove `isOverlayMode` parameter — no longer needed (overlay runs in separate isolate with its own entry point)
- Theme is now derived from SettingsProvider in the screen, not hardcoded in SpeedoApp
- Keep the MaterialApp with `useMaterial3: true` and base dark theme as fallback

**overlayMain() stays unchanged** — overlay runs in separate isolate and cannot access Provider.

void _startBackgroundHeartbeat() {
  _backgroundHeartbeatTimer = Timer.periodic(TimingConfig.HEARTBEAT_INTERVAL, (timer) {
    if (!mounted) return;
    final overlay = context.read<OverlayProvider>();
    if (_isInBackground && overlay.isOverlayActive) {
      overlay.pushCurrentData();
    }
  });
}
